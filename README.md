# stickarena
Stick Arena, tarayıcı üzerinden oynanabilen hızlı tempolu bir multiplayer arena oyunudur. Oyuncular kendi lobilerini oluşturabilir, arkadaşlarıyla veya diğer oyuncularla mücadele edebilir. Gerçek zamanlı maç sistemi, lobby yönetimi, oyuncu etkileşimleri ve dinamik arena yapısıyla tamamen web teknolojileri üzerine geliştirilmiştir.
