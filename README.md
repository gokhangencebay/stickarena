# 🎮 Stick Arena

**Stick Arena**, modern web teknolojileri kullanılarak geliştirilen, tarayıcı üzerinden oynanabilen gerçek zamanlı multiplayer arena oyunudur. Oyuncular kendi oyun lobilerini oluşturabilir, diğer oyuncuların lobilerine katılabilir ve dinamik arena ortamında hızlı tempolu maçlara katılabilir.

## 🚀 Proje Hakkında

Stick Arena'nın temel amacı, herhangi bir kurulum veya ek istemci gerektirmeden doğrudan web tarayıcısı üzerinden erişilebilen, hızlı ve rekabetçi bir multiplayer oyun deneyimi sunmaktır.

Proje; **lobby sistemi, oyuncu yönetimi, maç başlatma mekanizması, gerçek zamanlı oyuncu etkileşimleri ve dinamik oyun akışı** gibi temel multiplayer bileşenleri üzerine kurulmaktadır.

### ✨ Öne Çıkan Özellikler

- 🎮 Tarayıcı tabanlı oyun deneyimi
- 🌐 Multiplayer lobby sistemi
- 🏠 Oyun lobisi oluşturma ve katılma
- 👥 Oyuncu yönetimi ve lobby kontrolü
- ⚔️ Gerçek zamanlı arena maçları
- 🤖 Bot oyuncu desteği
- 🔄 Dinamik maç başlatma ve oyun akışı
- 📱 Web tabanlı ve farklı ekranlara uyarlanabilir yapı
- ⚡ Hızlı ve düşük gecikmeli oyun deneyimi hedefi
- 🧩 Geliştirilebilir modüler oyun altyapısı

## 🛠️ Geliştirme

Stick Arena, web tabanlı multiplayer oyun mimarisi üzerine geliştirilmeye devam eden aktif bir projedir. Yeni oyun mekanikleri, oyuncu sistemleri, haritalar, rekabet özellikleri ve backend geliştirmeleri ilerleyen sürümlerde projeye dahil edilecektir.
